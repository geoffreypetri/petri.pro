# Processus de gouvernance du Tech Radar

- **Responsables** : Architecture board (2–3 personnes).
- **Rythme** : Revue **trimestrielle** (30–45 min) + mise à jour **semestrielle** publique (changelog).
- **Règles** :
  - Tout ajout en **Assess/Trial** a un **owner** et des **KPIs**.
  - **Hold** n'interdit pas le run existant, mais bloque tout nouveau projet.
  - **Adopt** doit être disponible via des templates/boilerplates.
- **Traçabilité** : toute décision/modification est consignée dans le `CHANGELOG.md`.

## Modèle de décision (à copier dans les fiches)
- Contexte
- Hypothèses/contraintes
- Expérimentations/projets de référence
- KPIs suivis
- Décision et critères de réévaluation
